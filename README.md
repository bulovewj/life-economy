# 인생 살기 게임: 경제편

초등 고학년이 12살부터 80살까지 한 번의 인생을 살며 용돈·알바·직장·월세/전세·저축·투자·결혼·내 집·연금 같은 경제적 선택을 직접 해 보는 도트 텍스트 시뮬레이션이에요.
서버·로그인·생성형 AI 호출이 없고, 기록은 이 기기의 브라우저에만 저장돼요(외부 전송 없음). PC·갤럭시 탭·휴대폰 모두에서 열려요.

## 실행
- 내려받은 폴더의 `index.html`을 더블클릭하면 바로 실행돼요(인터넷 필요 없음).
- 학급 공유는 GitHub Pages 같은 주소에 올려서 링크를 나눠 주세요.

## 수업에서 쓰기
- 타이틀 아래 작은 **선생님 모드**에서 세계 번호(4자리)와 공정 모드를 정하고 **학급용 링크**를 복사해요.
- 같은 링크(`?seed=1234&fair=1`)로 들어오면 같은 해에 경기 침체가 와요. 같은 세계에서 누가 왜 달랐는지 토론할 수 있어요.
- 공정 모드(기본)는 모두 같은 시작 카드. 끄면(`fair=0`) 학생마다 시작 카드가 달라요.
- 40분 수업 예: 도입 5분 · 플레이 25분(자동 버튼 활용) · 짝과 엔딩 비교 5분 · 마디 답변으로 성찰 5분.
- 엔딩의 친구 4명은 AI가 아니라 정해진 규칙으로 움직여요. 엔딩 화면의 **인쇄**는 A4 한 장짜리 "나의 인생 보고서"예요.
- 별명을 쓰도록 안내해 주세요.

## 개발 (빌드 도구 없음)
- HTML + CSS + 바닐라 JS(클래식 `<script>`). 숫자는 모두 만원 단위 정수, 난수는 `LG.rng`(시드 기반)만 써요.
- 콘텐츠는 `data/`에만: 수치 `economy-data.js`, 갈림길 `events-*-data.js`, 운 카드 `random-events-data.js`, 용어 `terms-data.js`, 엔딩·친구 `endings-data.js`.
- 검증 스크립트(Node 필요):
  - `node tools/check-data.js` 시나리오 ID·문구 길이·금지어·마지막 선택지 검사
  - `node tools/sim.js 1000 events` 1,000번 자동 플레이(NaN·막힌 이벤트), `... npc` 친구 4명 분포
  - `node tools/balance.js 200` 선택지별 결과 표(밸런스)
  - `node tools/pxl-build.js` `assets/pxl/*.px.js` → `assets/img/*.png` + `sprites.js` 도트 빌드
