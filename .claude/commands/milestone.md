# 마일스톤 실행

CLAUDE.md와 CODING_PLAN.md를 읽고 현재 진행 중인(또는 다음) 마일스톤을 확인해라.
$ARGUMENTS 가 있으면 그 번호의 마일스톤을 진행한다.

규칙:
1. 시작 전에 이 마일스톤에서 만들/수정할 파일 목록을 먼저 보여줘라.
2. 완료 조건 체크리스트를 하나씩 구현하고, 항목마다 사용자가 어떻게 직접 실행해서 확인하면 되는지 알려줘라.
3. 계획에 없던 파일을 만들거나 다른 마일스톤 범위를 건드리게 되면 진행하지 말고 먼저 물어라.
4. 새 라이브러리 설치가 필요하면 설치 전에 반드시 물어라.
