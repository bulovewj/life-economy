# 세션 마무리

지금까지의 세션을 마무리한다. 순서대로 실행해라:

1. TypeScript 타입 체크와 빌드가 통과하는지 확인해라. 실패하면 마무리를 멈추고 먼저 고쳐라.
2. git 커밋해라. 메시지 형식: "M[마일스톤 번호]: [한 줄 요약]". 마일스톤이 완전히 끝난 상태면 `git tag`도 제안해라.
3. CLAUDE.md의 '현재 상태' 표를 갱신해라 (완료 ✅ / 진행 중 🔄 / 미착수 ⬜).
4. 다음 세션에서 주의할 점 1~2개를 CLAUDE.md 현재 상태 아래에 메모해라.
5. 오늘 세션 요약을 출력해라: 한 것 / 결정한 것과 이유 / 막혔던 것과 해결.
   (사용자가 이 요약을 Notion 개발 로그에 옮길 수 있는 형태로.)
