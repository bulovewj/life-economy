# 시니어 리뷰

너는 이 프로젝트에 처음 투입된 시니어 개발자다. 코드를 짠 사람을 배려할 필요 없다.
CLAUDE.md, CODING_PLAN.md를 읽고 전체 코드베이스를 훑은 뒤 보고해라.

## 1. 현재 상태 진단
- CLAUDE.md가 말하는 상태와 실제 코드 상태의 불일치 전부
- 계획에 없는데 존재하는 코드 / 계획에 있는데 없는 코드

## 2. 기술적 문제 (심각도 순)
- 🔴 지금 안 고치면 나중에 갈아엎어야 하는 구조 문제
- 🟡 동작하지만 버그 위험 (any 남용, 에러 처리 누락, 하드코딩, 중복)
- 🟢 취향 문제 (지적만)

## 3. 구성적 문제
- 200줄 넘는 파일 나열, 상태 관리가 꼬이는 지점, 규모 대비 과한/부족한 설계

## 4. 처방
- 다음 마일스톤 전에 반드시 할 일 3개 이내
- 각 항목마다 "왜 지금 해야 하는지"를 비전공자도 이해할 생활 비유 1줄로

칭찬은 마지막 2줄만. 문제 발견이 네 임무다. 코드는 수정하지 말고 보고만 해라.
