## 2. 기능 명세 [시나리오 → 화면 동작 → 데이터 흐름]

### F1 시드와 경제 역사
- 시나리오: 같은 반 아이들이 같은 링크로 들어오면 같은 해에 불황이 온다.
- 동작: 시작 시 `seed`(URL 또는 무작위 4자리) 결정 → S12/엔딩에 "세계 번호 1234" 표시.
- 데이터: `LG.rng.create(seed)` (mulberry32). `LG.economy.generateHistory(rng)` → 길이 69(12~80세) 배열 `{indexReturn, stockReturn, coinReturn, housing, inflation, depositRate, loanAdj, isRecession}`. 침체 연도: 33~37 중 1, 56~60 중 1, 그 외 15% 확률로 1회(앞뒤 5년 간격). **플레이어 선택용 난수와 역사 난수는 별도 스트림**(seed, seed+1)으로 분리 → 플레이어가 뭘 골라도 역사 동일.

### F2 1년 결산 (`LG.economy.settleYear(state, year)`)
순서 고정:
1. 소득 = Σ(직업 연봉) × 0.85 + 부업 + 연금 + 알바 (배우자 포함)
2. 지출 = 생활비(인원·물가 누적 반영) + 주거비 + 자녀비 + 차량 + 보험 + 이벤트 고정지출
3. 이자 = Σ(빚 × 금리), 원금 상환 = 할부/주담대 원리금균등
4. 남은 돈 = 소득 − 지출 − 이자 − 상환
5. 남은 돈 > 0: 저축비율만큼 → 투자 배분대로 각 자산에 매수, 나머지 현금
6. 남은 돈 < 0: 현금 → 비상금 → 예금 → 지수펀드 → 인기주 → 코인 순으로 충당, 그래도 모자라면 `debt:신용` 증가 + 경고 토스트 "돈이 모자라 빌렸어요(이자 7%)"
7. 자산 가격 갱신: 예금×(1+rate), 펀드×(1+indexReturn), 인기주, 코인, 집×(1+housing), 차×0.85
8. 연봉 ×1.03, 물가 누적 ×(1+inflation)
9. 기록: `history.push({age, netWorth, happiness, health, relation, skill, income, spend})`
- 순자산 = 자산 합 − 빚 합 (집 포함).
- 미성년(12~18)은 소득=용돈×12(+알바), 지출 없음(부모님 부담), 저축 = 쓰지 않은 용돈.

### F3 올해의 집중 (매년 1택, 갈림길 전에)
| 선택 | 효과 |
|---|---|
| 공부 | 실력+3, 행복−1 |
| 일과 돈 | 소득+5%(미성년은 알바 시간↑), 건강−1 |
| 건강과 여가 | 건강+2, 행복+2, 소득−0 |
| 사람 | 관계+3, 지출+3% |
능력치는 0~100 클램프. 자동 진행 중엔 직전 선택 유지.

### F4 이벤트 엔진 (`LG.events`)
- 데이터 스키마(`data/events-data.js`):
```js
{ id:'E01', age:[12,12], required:true, cond:(s)=>true, title:'용돈 받는 날', icon:'coin',
  text:'이번 달 용돈을 받았어요. 어떻게 할까요?',
  choices:[ { label:'먹고 싶은 거 다 사 먹는다', cond:(s)=>true, disabledReason:'',
              effects:[{t:'stat',k:'happiness',v:4}], chance:null, tip:'쓰는 즐거움은 크지만 금방 사라져요.', term:null } ] }
```
- `effects` 타입: `stat`, `cash`, `asset`, `debt`, `flag`, `job`, `path`, `setting`(저축률 등), `sub`(하위 선택), `delayed`(n년 뒤 효과), `recurring`(매년, 기간).
- `chance`: `[{p:0.5, effects:[...], tip:''}, ...]` 확률 분기는 플레이어 스트림 rng.
- 나이 범위 이벤트는 범위 안 무작위 1년에 배정(게임 시작 때 확정, 시드 결정적).
- 한 해에 갈림길 최대 1개 + 운 카드 최대 1장.

### F5 자동 진행
- [자동 ▶▶]: 갈림길·운 카드·마디가 나올 때까지 1년씩 0.6초 간격 진행. 화면 터치하면 멈춤.

### F6 저장
- localStorage 키 `lg_save_v1`: state 전체 JSON(함수 없음). 매년 결산 후 자동 저장.
- 키 `lg_answers_v1`: 마디 답변. 엔딩 후 [다시 살기]하면 둘 다 삭제 확인창.
- localStorage 불가 환경(시크릿 등): try/catch, 저장 없이 진행 + 타이틀에 "이 브라우저에선 이어하기가 안 돼요" 표시.

### F7 엔딩
- 인생 그래프: canvas 직접. x=나이, y1=순자산(만원, 좌축), y2=행복(우축 0~100). 침체 연도 회색 띠. 내 선택 지점에 점(탭하면 이벤트 이름).
- 친구 4명: 같은 역사로 `LG.npc.simulate(policy, seed)` 즉시 계산 → 순자산 곡선 4개 얇은 선 + 표(순자산, 행복, 관계, 칭호).
- 하단 문구: "이 친구들은 정해진 규칙대로 움직이는 프로그램이에요."
- [인쇄]: `@media print` A4 1장 — 별명, 세계 번호, 그래프, 칭호, 마디 답변 5개, 선택 타임라인 요약.

### F8 선생님 모드
- 진입: 타이틀 하단 작은 링크(학생이 굳이 안 누르게 작게). 비밀번호 없음.
- 설정은 URL 파라미터로만 전달(저장 안 함). `fair=1`이 기본값, `fair=0`이면 시작 카드 무작위.

## 3. 엣지 케이스
| 상황 | 처리 |
|---|---|
| 선택지 비용이 현금보다 큼 | 회색 + "모은 돈이 ○○만원 부족해요" |
| 모든 선택지가 불가 | 마지막 선택지는 항상 가능하게 데이터 작성(검증 스크립트로 확인) |
| 빚이 순자산의 3배 초과 | "빚 상담 받기" 운 카드 강제(금리 7→4%로 조정, 행복−5) — 게임오버 없음 |
| 직업 없음 2년 이상 | 최저임금 일자리 자동 제안 이벤트 |
| 저장 데이터 버전 다름 | 이어하기 숨김, 새로 시작 |
| 화면 회전·창 크기 변경 | 그래프 다시 그리기 |
| 이름 비움 | "이름 없는 여행자" |
| 이름에 욕설 | 간단 금칙어 10개 정도 → "다른 별명을 써 볼까요?" |
