# 기획서 — 인생 살기 게임: 경제편

> 작성: 2026-10-27 / 형이 자는 동안 인터뷰 없이 작성 → **[가정]** 표시는 형이 확인·수정할 부분.

## 1. 한 줄 정의
초등 고학년이 **12살 지금의 나**에서 출발해 80살까지 살아 보며, "같은 세상에서도 선택과 운에 따라 인생이 달라진다"는 걸 경제적 선택으로 체험하는 시뮬레이션.

## 2. 모티브 「80억분의 1」 분석 → 무엇을 가져오고 무엇을 바꾸나
| 원작 요소 | 원작 | 우리 게임 |
|---|---|---|
| 무작위 출생 | 172개국 중 무작위, 국가 통계가 인생을 좌우 | **시작 카드 3장**(가정의 지원 정도·사는 곳·타고난 재능)만 무작위. 교사가 "공정 모드"로 끌 수 있음 |
| 시간 흐름 | 1년 ≈ 40~60초, 매년 공부/일/가족/건강 중 집중 선택 | 1년 = 1턴. 매년 **올해의 집중** 4택(공부·일과 돈·건강과 여가·사람). 이벤트 없는 해는 자동 진행(배속) |
| 갈림길 | 진학·취업·연애·이주 등 | **경제 갈림길 34개**(시나리오.md) |
| 생애 마디 | 5·15·30·50·70세 한 줄 질문 | **12·20·30·50·70세** 한 줄 질문 → 엔딩에서 모아 보기(활동지 연계) |
| 엔딩 | 같은 시간에 태어난 다른 사람들의 삶 나란히 | **같은 날 태어난 친구 4명**(성향이 다른 AI)과 같은 경제 역사 속 결과 비교 |
| 경제 위기 | 약 10년마다 불황·금융위기 | 35세 전후·58세 전후 **경기 침체 2회 고정** + 랜덤 1회 |
| 점수 | 없음 | 단일 점수 없음. 돈·행복·건강·관계·꿈 5영역 + 칭호 |
| 무거운 장면 | 아동 사망·분쟁 등, 15세 이상 권장 | 사망·질병 사망·이혼 제외. 실직·사기·부채는 "배울 거리"로 포함 |

원작은 "태어난 곳이 거의 다 정한다"가 메시지. 우리는 **"출발(운) + 선택 + 우연"이 섞여 인생이 된다**로 바꾼다. 같은 시드에서 친구 4명이 다른 결과를 내는 엔딩이 이걸 눈으로 보여 줌.

> 참고: 원작은 1인 개발자가 Claude로 약 4시간 만에 바이브 코딩해 만든 웹게임으로 알려짐 → 형이 학생들에게 "이런 것도 AI랑 만들 수 있다" 사례로 써도 좋음.

## 3. 교육적 설계
- **교과 연계 [가정]**: 6학년 사회 경제 단원(가계·기업의 합리적 선택), 실과 생활 자원 관리, 창체 진로. 성취기준 코드는 형이 교육과정 문서로 확인.
- **핵심 개념 18개 = 용어 카드**: 기회비용, 필요와 욕구, 저축, 이자·복리, 물가(인플레이션), 최저임금, 근로계약서, 세전·세후, 비상금, 신용·할부, 월세·전세·보증금, 대출·금리, 분산투자, 위험과 수익, 금융사기, 보험, 연금, 감가상각.
- **생성형 AI 미사용**: 게임 안에 AI 호출 없음(형의 수업 철학과 일치). "친구 4명"도 규칙 기반 프로그램이라고 엔딩에서 밝힘 → "이 친구들은 정해진 규칙대로 움직였어요" 한 줄. AI 원리 수업 소재로도 활용 가능.
- **판단 금지 원칙**: 결혼/비혼, 자녀 유무, 집 소유/임차, 직업 종류에 우열 문구 없음. 결과 수치만 보여 주고 해석은 아이가.
- **수업 흐름 예시**: 도입 5분(오늘 너의 인생 지갑) → 플레이 25분 → 짝과 엔딩 비교 5분 → 마디 답변으로 성찰 5분. 교사 모드로 반 전체 같은 시드 → "같은 불황에서 누구는 왜 괜찮았을까?" 토론.

## 4. 게임 루프
1. **시작**: 이름(별명) 입력 → 아바타 4종 중 선택 → 시작 카드 3장 뒤집기.
2. **매년**: 올해의 집중 선택 → (해당 나이 이벤트 있으면) 갈림길 → 랜덤 운 카드(확률) → 1년 결산 토스트(+수입 −지출 =남은 돈).
3. **마디(12·20·30·50·70세)**: 시간 멈춤, 한 줄 쓰기(건너뛰기 가능).
4. **80세 엔딩**: 인생 그래프(자산·행복 두 줄), 5영역 막대, 칭호 1~3개, 친구 4명 비교, 내가 한 선택 타임라인, 획득 용어 카드, 인쇄용 "나의 인생 보고서".

## 5. 시스템 요약 (자세한 공식은 작업지시서 §4)
- **능력치 4개(0~100)**: 행복·건강·관계·실력. **돈**: 현금·예금·지수펀드·인기주·코인·집·차 / 빚(학자금·신용·전세·주담대·카드).
- **1년 결산**: 세후 소득 − 생활비 − 주거비 − 이자·원금 − 이벤트 지출 → 자동 저축 비율만큼 예금, 남으면 현금. 현금이 마이너스면 자동 처리 순서(현금→예금→펀드→신용대출) + 경고.
- **시장**: 시드 난수로 80년치 경제 역사를 게임 시작 때 한 번에 생성(수익률·물가·집값·금리). 같은 시드 = 같은 역사.
- **20세 이후 저축·투자 설정 화면**(언제든 수정 가능): 월급 중 저축 비율(0/10/20/30/50%), 투자 배분 슬라이더 4개(예금/지수펀드/인기주/코인).

## 7. 이미지 결정: **claude-pxl 도트가 메인, GPT 이미지는 안 씀(선택 사항)**
- 이유 ① 일관성: 생성형 이미지는 장마다 그림체가 흔들림. 도트+고정 팔레트는 100장이어도 한 화풍.
- 이유 ② 수정: "모자 색만 바꿔" 같은 요청이 코드 한 줄. GPT 이미지는 다시 뽑기 도박.
- 이유 ③ 분량: 필요한 그림이 작다(캐릭터 6연령×4아바타, 배경 6장, 아이콘 ~40개). pxl로 충분.
- 이유 ④ 수업 철학: 학생 화면에 생성형 AI 이미지를 굳이 넣지 않아도 됨.
- 예외: 타이틀 키아트 한 장이 꼭 화려해야 하면 GPT 이미지로 만들고 **도트풍으로 축소·팔레트 감소** 후 사용(에셋가이드.md §5 프롬프트 템플릿).

## 8. 확인 필요 [가정] 목록 — 형이 일어나서 보고 정할 것
1. 대상 학년: 5~6학년 가정. 4학년까지 내리면 문장·숫자 더 단순화 필요.
2. 금액 표기: **실제 원화(만원 단위)** 가정. "게임 화폐(코인)"로 바꿀지?
3. 시작 카드의 "가정의 지원 정도" 무작위: 민감할 수 있어 **기본값 = 공정 모드(모두 같음)**, 교사가 켜면 무작위. 반대로 할지?
4. 기기: 학교 크롬북/태블릿 + 교사 PC 가정 → 세로/가로 모두 대응.
5. 이름: 실명 대신 별명 입력 권장 문구 넣음(개인정보).
