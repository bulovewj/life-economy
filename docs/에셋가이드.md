# 에셋가이드 — 이미지 만들기

## 1. 결정
- **메인: claude-pxl** (Claude가 `.px.js` 코드로 도트를 그리고 PNG·스프라이트 시트·GIF로 빌드).
- **보조(선택): GPT 이미지** — 타이틀 키아트 1장만, 필요할 때. 나머지는 쓰지 않는다.
- **안 씀: sprite-gen** — 걷기·뛰기 애니메이션용이라 과함, codex·ffmpeg·img2webp 설치 필요.

## 2. claude-pxl 설치 (M6 시작 전에 형이 한 번)
```bash
# Node 22.18 이상 필요: node -v 로 확인
cd ~/dev/life-economy-game
git clone https://github.com/crsolver/claude-pxl .claude/skills/pxl-pixel-art
node .claude/skills/pxl-pixel-art/bin/pxl.js --help
```
- Claude Code 재시작 → 스킬 인식. 작업 지시: "pxl 스킬로 assets/pxl/에 그려".
- `.gitignore`에 `.claude/skills/pxl-pixel-art/` 추가(남의 레포를 우리 레포에 섞지 않음). 빌드 결과 PNG만 커밋.
- 미리보기: `node .claude/skills/pxl-pixel-art/bin/pxl.js serve` → http://localhost:4321 (저장할 때마다 다시 그려줌).
- 막히면: `ascii` 명령으로 그림을 글자판으로 찍어 Claude가 스스로 확인하게 시킨다.

## 3. 스타일 규칙 (모든 에셋 공통)
- 팔레트: **sweetie16 고정**(16색, 따뜻하고 부드러운 톤). 다른 색 추가 금지. 형이 더 연한 파스텔을 원하면 M6에서 팔레트 한 번만 교체.
- 외곽선: 자동 외곽선 켬, 가장 어두운 색.
- 배율: 원본 1x로 만들고 CSS `image-rendering: pixelated`로 확대(4x). PNG를 미리 키워서 저장하지 않는다.
- 광원: 왼쪽 위. 그림자 1단계만.

## 5. (선택) GPT 이미지로 타이틀 키아트 만들 때
- 원칙: GPT 그림은 **구도 참고용 스케치**로만 쓴다. ChatGPT에서 생성 → 형이 `assets/ref/title-ref.png`로 저장 → Claude Code가 그림을 보고 pxl로 160×90에 **다시 그린다**. (생성 이미지를 그대로 넣으면 화풍이 섞임. `assets/ref/`는 커밋 제외)
- 프롬프트 템플릿:
```
16-bit pixel art, cozy pastel palette, a small child standing at a fork in a long road
that winds from a school toward a city and then to a seaside house, coins floating
softly like fireflies, warm sunset, no text, no logos, no real brands, 16:9
```
- 실존 캐릭터·브랜드·로고 요청 금지. 학생 얼굴 사진 넣지 않기.
